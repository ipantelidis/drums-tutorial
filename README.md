# Rock Drum Course

A single file interactive drum course: curriculum with pass tests, theory, reading (notation and tabs), technique, rhythm library, 3D kit, metronome, groove player with MIDI scoring, practice tools.

Everything is in `index.html`. No build step, no server. Open it locally or serve it as a static site.

Live version: https://ipantelidis.github.io/drums-tutorial/

## Notes

- MIDI input needs Chrome or Edge over HTTPS (GitHub Pages provides HTTPS).
- The 3D kit loads Three.js from cdnjs the first time it is opened.
- Progress is stored in the visitor's own browser (localStorage). Export and import from the Practice tab.
- All exercises are original. Named drummers are described, not transcribed.
